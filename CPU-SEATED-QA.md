# CPU AI and seated office — 2026-10-26

## Release scope
Existing Render static site only. No paid model API, Oracle instance, new Render service or server inference. This update addresses unavailable WebGPU and the standing-only artwork; it does not implement missing 用神／格局／應期 calculations.

## Actual model path
Opt-in download → capability check → WebGPU 1.5B or CPU/WASM 0.5B → dedicated Worker → generated response → plain-text conversation. Without a GPU adapter, the UI now offers CPU instead of disabling download. CPU may also be explicitly selected. No model files are requested before consent. A browser with neither WebAssembly nor a usable GPU still cannot run a model.

CPU model: `onnx-community/Qwen2.5-0.5B-Instruct`, q8, revision `22942cb7d7ba4cc81bb4673549ca4d4614469b5e`. The weight file is 512,096,557 bytes, plus tokenizer/config and approximately 24 MB of runtime/conversion assets. Runtime is vendored Transformers.js 3.7.2 and its matching ONNX WASM. Single-thread `device:wasm` does not require WebGPU or SharedArrayBuffer. OpenCC 1.4.2 converts generated text to Hong Kong Traditional Chinese without changing its semantic content.

### Evidence and limitations
- An actual IAB session with no usable WebGPU loaded the CPU model and completed multiple generated answers, including a family-housework message and a follow-up rewrite. This was not a mocked response.
- Cancelling during generation terminated the Worker and returned the UI to off; returning to lobby cleared the session.
- Actual output exposed a real limitation: a message requested for Sunday sometimes said Saturday, and a longer prompt produced irrelevant elaboration. The compact prompt no longer conflicts with a request for one sentence. The final code additionally rejects draft responses with wrong/missing explicit weekdays rather than rewriting them or presenting them as valid answers. Rejected answers are not added to model history and do not unload the engine.
- This is not evidence of professional astrology accuracy, GPT-equivalent dialogue, or universal phone compatibility. Low-memory devices may fail to load; CPU responses can take minutes. Errors are not replaced with canned text pretending to be generated.
- Context is bounded in CPU mode (350 characters of chart facts, two short history messages, 128 new tokens). Full deterministic chart reports remain separate and are not claimed to have been generated by the model.

## Verification
