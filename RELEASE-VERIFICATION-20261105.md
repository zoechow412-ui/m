# 2026-11-05 release verification

## Scope

Release contains chart-bound BaZi structural evidence (month principal qi, same-element roots and month hidden stems exposed in non-day stems), clickable definitions, and eight distinct interpretation policies. These are not a complete useful-god, pattern or event-timing engine.

## Verified locally

- Structural evidence tests and 11 interpretation-policy assertions passed.
- Existing explorer 13 checks, including 240 Ziwei charts, passed.
- Calculation regressions: 100 ten-god pairs, 12 Ziwei boundaries, 4096 coin patterns, Meihua lunar-year boundary, three Qimen device zones and seven-method aggregation passed.
- 25 astronomy/time-zone checks, 24 mocked model lifecycle tests, seat geometry and draft-answer tests passed.
- Browser: lobby, consultant selection, room entry, empty birth-date field, synthetic date/time, location, gender, family topic, question/context, calculation, full report. Actual month/root/exposure rows render with independent term buttons.

## Not certified

No scientific predictive accuracy is claimed. Full useful-god/pattern/event timing, comprehensive Vedic and Qimen interpretation, genuine arbitrary model dialogue and exhaustive browser coverage remain incomplete. Mocked model lifecycle tests are not real inference tests. Existing experimental CPU-model changes are deliberately excluded from this release.

## Deployment

Only selected root files and matching dist release assets are staged. No unrelated user assets or concurrent project files are included. Public verification follows deployment.
